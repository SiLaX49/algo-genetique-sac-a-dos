Le problème

max  Σ vᵢ xᵢ
s.c. Σ pᵢ xᵢ ≤ C,   xᵢ ∈ {0, 1}

Un chromosome = une chaîne de n bits, un gène par objet, 1 = objet pris. Exemple du fil rouge : .

Les réglages du cours

La boucle

t ← 0 ; stagnation ← 0
P ← N chromosomes aléatoires, réparés, évalués
TANT QUE t < Gmax ET stagnation < Smax
    roulette ; N/2 couples
    croisement (pc), mutation (pm), réparation
    élitisme ; t ← t + 1 ; mise à jour stagnation
RENVOYER le meilleur chromosome rencontré

Les formules à savoir refaire

  • Fitness : f = Σ vᵢ xᵢ, calculée après réparation.
  • Réparation : tant que le poids dépasse C, retirer l'objet pris de plus petit rapport v/p (lettre la plus basse en cas d'égalité). Ordre du fil rouge : .
  • Roulette : Pᵢ = fᵢ / Σf ; on prend le premier individu dont le cumul est strictement supérieur au tirage.
  • Croisement : si r < pc, point = ⌊r × (n − 1)⌋ + 1 et on échange les queues.
  • Mutation : chaque gène bascule si son tirage est < pm.
  • Élitisme : si le meilleur parent bat strictement le meilleur enfant, il remplace le pire enfant.
  • Arrêt : t = Gmax ou Smax générations sans nouveau record.

Pièges fréquents

  • Oublier de réparer après la mutation : le sac peut redevenir trop lourd.
  • Calculer la roulette sur les poids, ou sur les fitness d'avant réparation.
  • Confondre pc (un tirage par couple) et pm (un tirage par gène).
  • Retirer l'objet le plus lourd : la règle vise le plus petit rapport v/p.
  • Écrire « tirage ≤ cumul » dans la roulette, alors que la condition est « tirage < cumul ».
  • Conclure à l'optimum parce que l'algorithme s'est arrêté.
